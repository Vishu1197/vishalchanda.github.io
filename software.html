Research software

Eight open source tools, all of them written because a step in my own pipeline was slower, vaguer or more error prone than it needed to be. Together they cover the whole path from a PDB identifier to a quality checked molecular dynamics trajectory. MIT licensed, on GitHub.

DockPred

Live

Binding affinity from descriptors alone, learned from 8.7 million docking runs.

A machine learning and deep learning ensemble that predicts protein ligand docking scores in kcal/mol straight from precomputed molecular descriptors. It puts a fast filter in front of the expensive docking step, so the compounds that reach Vina are the ones already worth the compute.

Python 3.10+scikit-learn PyTorchLightGBM XGBoostCatBoostOptuna
Repository

DockMate

Live

One receptor, an entire ligand library, one ranked affinity table.

Drives Chimera's native Vina command headlessly across a ligand folder, keeping Chimera's receptor preparation and ViewDock compatible output while removing the click through workflow. Results are identical to docking by hand, and every generated command file is preserved for audit and reproducibility. Box validation, resumable runs and isolated per ligand processes come as standard.

Python, stdlib onlyUCSF Chimera 1.19 AutoDock VinaWindows / Linux / macOS
Repository

GridMate

Live

Measured docking boxes, not the customary 25 Å guess.

Closes the gap P2Rank leaves open. Pocket prediction returns ranked centres and confidence scores but says nothing about search volume, so box size is usually assumed, either oversampling empty solvent or clipping the ligand's rotational freedom. GridMate derives the box from the coordinates of the atoms lining each pocket plus headroom, making the dimension a measurement rather than a convention.

PythonP2Rank 2.5Pairs with DockMate
Repository

DynaMate

Live

100, 200 or 500 ns of molecular dynamics on the protein as it crystallised. Cofactor, metal ion and all.

Addresses a real modelling error rather than a convenience problem. A GTPase carries GDP and Mg2+, a kinase carries ATP, a dehydrogenase carries NAD+. Stripping those out to satisfy the force field simulates a protein that does not exist. DynaMate keeps the holo system intact and parameterises it properly. Drop a receptor and a ligand into a working directory and run it.

ShellGROMACS 2021+ AmberToolsGAFF2 / AM1-BCC PythonLinux WSL2
Repository

BioSimBench

Live

Quality control for GROMACS runs, before you trust the trajectory.

Inspects a simulation directory, performs structural and metadata level checks, and writes a standalone HTML report. It detects the expected files, extracts parameters from the configuration, scans the logs for completion status and error patterns, and returns PASS, WARN or FAIL against each check. Roadmap runs through energy analysis, structural analysis and a full research dashboard.

Python 3GROMACS pytestHTML reporting
Repository

PDB-Harvester

Live

Harvesting protein structures seamlessly from global PDB archives.

A command line utility that pulls 3D structures in PDB and mmCIF format from the RCSB, wwPDB, PDBe and PDBj mirrors, with failover between them, resumable streaming downloads, retry with exponential backoff, and a JSON log of exactly what came back. Built for the moment a screening campaign needs four hundred structures and a flaky connection.

PythonRCSB PDB API Multi mirror failoverJSON logging
Repository

Protein Descriptor PDBID

Live

Per protein descriptors straight out of a structure file.

Detects, parses and computes per protein descriptors, hydrogen bond donors and acceptors and molecular mass, from PDB and mmCIF files. Robust to the encoding surprises that structure files are full of, and shaped so its output drops into a downstream machine learning or docking workflow without reformatting.

Python 3.8+Biopython pandasPDB / mmCIF
Repository

ChemBL2PubChem-Bridge

Live

Maps ChEMBL identifiers to PubChem CIDs and keeps every original column.

ChEMBL and PubChem use incompatible identifier systems, which quietly breaks any workflow that draws on both. This bridges them, turning CHEMBL25 into 2244 while preserving the rest of the row, and writes a CID based docking CSV ready for the next stage. Pure standard library, querying PubChem's public REST API with no credentials.

Python 3.8+Zero dependencies PubChem RESTChEMBL
Repository
